## Descripción

SaaS completo para gestión de un gym, con múltiples roles, funciones por cargo y marketplace.

## Características
- Gestión de usuarios
- Control de acceso
- Funciones específicas para cada rol
- Integración de marketplace
  
  <img width="800" height="599" alt="image" src="https://github.com/user-attachments/assets/c8077d46-db64-4e52-99bb-8397896ee8f7" />


## Roles y permisos
- Administrador: Gestión total de la plataforma.
  
  <img width="800" height="599" alt="image" src="https://github.com/user-attachments/assets/c8a114f5-a16b-4bb8-8898-cce87dab7b7e" />
- Entrenador: Gestión de usuarios y planes de entrenamiento.
- Usuario: Acceso a su perfil y compras en el marketplace.

## Tecnologías
- TypeScript

## Instalación local
1. Clona el repositorio.
2. Instala las dependencias: `npm install`
3. Inicia el servidor: `npm start`

## Variables de entorno
Asegúrate de configurar las siguientes variables:
- `DATABASE_URL`
- `API_KEY`

## Scripts
- `npm run build` - Compila el proyecto.
- `npm test` - Ejecuta las pruebas.

## Estructura del proyecto
- `/src` - Código fuente.
- `/docs` - Documentación.
